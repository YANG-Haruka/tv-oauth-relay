# tv-oauth-relay

电视桌面（dangbei-f3 / cytv-launcher）「扫码登录 Google」用的中转页。

流程：电视上显示二维码 → 手机扫码、登录 Google、点「允许」→ Google 只能跳回公网 HTTPS 地址，于是跳到这个页面 →
页面在手机浏览器里马上把授权码交给家里局域网里的电视（电视的地址在 `state` 里，是它画二维码时放进去的）。

- 纯静态页面：不存任何东西，也不把授权码发到别处。
- 只接受局域网地址（10.x / 172.16–31.x / 192.168.x / 169.254.x），别人做的链接没法把授权码引到公网服务器。
- 所有人共用这一个页面：克隆电视桌面后不需要自己部署。
